Kebijakan Privasi — Logichild

Terakhir diperbarui: 26 Agustus 2026  •  Berlaku untuk aplikasi Logichild (Android)

Ringkasan singkat untuk orang tua: Logichild TIDAK mengumpulkan data pribadi anak. Semua kemajuan permainan tersimpan lokal di perangkat. Aplikasi menampilkan iklan melalui Google AdMob yang disajikan secara aman untuk anak (non-personalized / child-directed sesuai kebijakan Google & COPPA).

1. Tentang Aplikasi Ini

Logichild adalah aplikasi permainan edukasi logika untuk anak usia 2–5 tahun yang dikembangkan oleh Yovi Eka Putra. Aplikasi dirancang untuk dapat digunakan tanpa internet dan tanpa akun.

2. Data yang Kami Kumpulkan

Kami tidak mengumpulkan, menyimpan, atau mengirimkan data pribadi apa pun dari pengguna, termasuk anak-anak. Secara rinci:

  • Tidak ada akun atau pendaftaran — aplikasi tidak meminta nama, email, atau data identitas lain.
  • Tidak ada pelacakan lokasi, akses kontak, galeri, mikrofon, atau kamera.
  • Kemajuan permainan disimpan secara lokal di perangkat pengguna (mis. level yang sudah dicapai, bintang, pengaturan suara, timer). Data ini tidak pernah dikirim ke server kami.

3. Iklan (Google AdMob)

Logichild menampilkan iklan melalui layanan Google AdMob. Sesuai kebijakan aplikasi untuk anak (Google Families / COPPA), iklan disajikan dalam mode child-directed dengan konten iklan terbatas dan non-personalized.

Google dapat memproses data teknis terbatas terkait perangkat (misalnya ID iklan perangkat, jenis perangkat, data koneksi) untuk keperluan penyajian iklan, sesuai Kebijakan Privasi Google. Kami tidak menerima maupun menggunakan data tersebut untuk keperluan lain.

4. Kontrol Orang Tua

Untuk melindungi anak, aplikasi menyediakan:

  • Parent gate — akses ke pengaturan dan alur tertentu di balik soal matematika sederhana.
  • Timer bermain — orang tua dapat mengatur batas waktu layar; saat habis, anak diingatkan untuk istirahat.
  • Iklan di area non-bermain — iklan tidak mengganggu saat anak bermain.

5. Berbagi Data

Kami tidak menjual, menyewakan, atau membagikan data pribadi kepada pihak ketiga mana pun. Satu-satunya pihak ketiga yang terlibat adalah Google (AdMob) untuk penyajian iklan sebagaimana dijelaskan di atas.

6. Keamanan

Karena data permainan tersimpan sepenuhnya lokal di perangkat dan tidak ada komunikasi data pengguna ke server, risiko privasi sangat minim. Data dapat dihapus kapan saja dengan menghapus aplikasi atau data aplikasi.

7. Perubahan Kebijakan

Kebijakan ini dapat diperbarui sewaktu-waktu. Perubahan akan diumumkan pada halaman ini beserta tanggal pembaruan. Penggunaan aplikasi setelah perubahan berarti menyetujui kebijakan terbaru.
